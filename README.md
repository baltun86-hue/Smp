# СМП Справочник — iOS-приложение

Веб-версия (`www/index.html`) обёрнута в нативный iOS-проект через [Capacitor](https://capacitorjs.com) — Xcode-проект уже сгенерирован в `ios/App`. Всё содержимое справочника (алгоритмы, дозировки, шкалы) работает офлайн внутри самого приложения, сеть ему не нужна.

## Что нужно сделать на Mac

### 1. Открыть проект

```
git clone <этот репозиторий>
cd <репозиторий>
npm install
npx cap open ios
```

Последняя команда откроет `ios/App/App.xcworkspace` в Xcode (CocoaPods не используется — зависимости через Swift Package Manager, поэтому `pod install` не нужен).

### 2. Настроить подпись (signing)

В Xcode: выбери проект **App** в навигаторе → таргет **App** → вкладка **Signing & Capabilities**:
- **Team** — выбери свой Apple Developer аккаунт (нужен платный, $99/год, для публикации в App Store; бесплатный Apple ID подойдёт только для локального запуска на своём телефоне).
- **Bundle Identifier** — сейчас `ru.smpspravochnik.app` (задан в `capacitor.config.json`). Смени на свой уникальный (например `com.твойник.smphandbook`), если нужен другой — тогда поменяй его в трёх местах: `capacitor.config.json`, `ios/App/App.xcodeproj` (само поле в Xcode) и создай соответствующий App ID в Apple Developer.

### 3. Проверить на устройстве

Подключи iPhone по кабелю, выбери его в списке устройств сверху и нажми ▶️ Run. При первом запуске на телефоне: Настройки → Основные → VPN и управление устройством → довериться профилю разработчика.

### 4. Иконка и заставка

Уже сгенерированы из фирменного знака справочника (тёмно-синий квадрат с белым крестом) и лежат в `ios/App/App/Assets.xcassets`. Если хочешь свою иконку — положи новый квадратный PNG 1024×1024 без прозрачности в `resources/icon.png` и выполни:

```
npx capacitor-assets generate --ios
```

### 5. Архивация и загрузка в App Store Connect

В Xcode: **Product → Archive** (нужно выбрать "Any iOS Device", а не симулятор). После сборки откроется Organizer → **Distribute App** → **App Store Connect** → **Upload**.

### 6. Карточка приложения в App Store Connect

На [appstoreconnect.apple.com](https://appstoreconnect.apple.com) (нужен Apple Developer аккаунт):
- Создай новое приложение, укажи тот же Bundle ID.
- **Скриншоты** — минимум для одного размера экрана iPhone (сделай в симуляторе через Xcode: Cmd+S в запущенном приложении).
- **Политика конфиденциальности (Privacy Policy URL)** — обязательна, даже если приложение ничего не собирает. Можно разместить простую страницу-заглушку (например через GitHub Pages) с текстом, что приложение не собирает и не передаёт никаких данных — всё хранится локально на устройстве (`localStorage`: тема, размер шрифта, отредактированные карточки).
- **App Privacy** (раздел "Конфиденциальность данных") — можно честно указать "Данные не собираются" (Data Not Collected), так как приложение полностью офлайн.
- **Возрастной рейтинг** — пройди опросник; справочник содержит медицинскую информацию (дозировки, алгоритмы), но не является жестоким/шокирующим контентом.
- **Медицинский дисклеймер** — в приложении уже есть текст в разделе «О программе» о том, что справочник носит справочный характер и не заменяет клинические рекомендации. Apple обычно требует такой дисклеймер для медицинских приложений (App Review Guideline 1.4.1) — держи его на видном месте (можно продублировать в описании приложения в App Store).

### 7. Отправка на ревью

После загрузки сборки в App Store Connect: выбери её в карточке версии → **Submit for Review**. Модерация обычно занимает от нескольких часов до пары дней.

## Структура репозитория

- `www/index.html` — сам справочник (весь код в одном файле, адаптирован под iOS: без авто-zoom по тапу на поля, без авто-распознавания телефонов в дозировках, нативный скролл).
- `capacitor.config.json` — конфигурация обёртки (appId, appName).
- `ios/` — сгенерированный Xcode-проект.
- `resources/icon.png` — исходник иконки 1024×1024 для генерации иконок всех размеров.

## Обновление содержимого справочника

Правишь `www/index.html` → `npx cap sync ios` → пересобираешь в Xcode. Обёртка ничего не меняет в самом справочнике, просто показывает его в нативном окне без браузерных элементов.
