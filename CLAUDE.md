# СМП Справочник — инструкция для Claude Code

## Контекст
Офлайн-справочник для бригад скорой медицинской помощи (ГАУЗ «Альметьевская ССМП», Татарстан):
препараты и дозы, алгоритмы, шаблоны карт вызова, атлас ЭКГ, МКБ-10, шкалы и калькуляторы,
статус и симптомы, приказы и маршрутизация по г. Альметьевску.

Пользователь — фельдшер/врач на вызове: телефон в одной руке, нет связи, нет времени.
**Главный критерий любой правки: быстрее и безопаснее найти нужное на вызове.**

Ты одновременно: (1) frontend-разработчик на чистом HTML/CSS/JS;
(2) медицинский редактор — дозы и алгоритмы проверяешь так же строго, как код.

## Репозиторий
- `www/index.html` (~3 МБ) — всё приложение: данные, стили, скрипты, иконки. PWA, офлайн.
- `ios/`, `capacitor.config.json`, `package.json`, `resources/` — iOS-обёртка (Capacitor),
  `webDir: "www"`. После правки `www/index.html` для iOS — `npx cap sync ios` (на Mac).
- `tools/` — служебные скрипты проверки (Python/Node). Создаются по мере необходимости.
- `docs/МОССМП-2026.md` — текст МОССМП 2026 (Московская обл.), опорный источник алгоритмов.
  Сверять дозы по нему (Grep, не читать целиком); в отчётах ссылаться на номер строки.
- Опубликованная версия: https://claude.ai/artifact/KFCFvddCjv5Ww3wge2gbx2
  (публикую сам через claude.ai; из Claude Code не публикуется).
- Версия — константа `VERSION`, в файле записана без пробелов: `VERSION="6.87 (09.10.2026)"`.
  Поиск и `tools/validate.py` — по регулярке `VERSION\s*=\s*"([^"]+)"`, при правке
  сохранять исходное написание (без пробелов).
- Источник правды — `www/index.html` в рабочей ветке. Не работать по памяти и старым копиям.
  Если VERSION в файле меньше опубликованной — сначала сказать мне, правок не вносить.
  Если положу рядом другой `index.html` с тем же VERSION — не выбирать самому:
  сводка различий (разделы, сколько записей добавлено/изменено/удалено, 1–2 примера)
  и вопрос: заменить, объединить или только отчёт.

## Вкладки (порядок и навигацию не менять без просьбы)
Все препараты · Алгоритмы СМП · Шаблоны карт · ЭКГ · МКБ-10 · Шкалы и калькуляторы ·
Статус и симптомы · Приказы и маршрутизация.

## Структуры данных (строго)
**DRUGS** — массив. Обязательно: `n` (название), `lat` (пропись), `r` (пути введения),
`det` (кратко: возраст/доза), `g` (группа), `minAge` (в МЕСЯЦАХ).
Для расчёта: `conc` (мг/мл), `amp` (мл в ампуле), `dose {unit, lo, hi}`, `maxSingle`,
`maxCumulative {unit, val, note}`, `fixedAdult {txt, note, minAgeMonths}`, `noCalc`.
Дополнительно: `adm {dilute}`, `contra`, `indic`, `conflict`, `note`, `a45*` (детские дозы).

**STANDARDS** — объект «специальность → массив алгоритмов». Поля: `t`, `icd` (через запятую),
`dx []`, `steps [[условие, действие]]`, `tactic`, `kit []`,
`doses [{drug, adultDose, pediatricDose, maxDose, route, repeat, dilute, calcByWeight, note}]`.

Прочее: `SCEN`, `CARD_TEMPLATES`, `ECG2_DATA` (id, cat, urgency, title, artery, affected,
leadsSte, leadsStd, redFlag…), `ICD10_FULL`, `SCALES`, `ORDERS`, `REFERENCE`, `INFUS_PRESETS`.

### Связность
- Каждое имя в `kit` и `SCEN` есть в `DRUGS` (по `n`). Нет — добавь или сообщи.
- Дозы в `STANDARDS.doses` не противоречат `DRUGS` того же препарата.
- `CARD_TEMPLATES[].std` совпадает со специальностью в `STANDARDS`.
- Новые поля — только при необходимости, с объяснением зачем и где используются.

## Как вносить правки
1. Файл не переписывать целиком, данные не перепечатывать вручную. Только точечно:
   Python-скрипт (извлечь константу → JSON-разбор → изменение → обратная запись) или
   Edit по точному фрагменту. Всё вне задачи — байт в байт.
   Не читать `index.html` целиком в контекст — искать Grep'ом, читать нужные диапазоны.
2. Массовые правки (десятки записей): сначала план и 2–3 примера «было → стало»,
   выполнять после подтверждения.
3. Перед правкой — отдельная git-ветка или хотя бы чистый `git status`; после — коммит
   с понятным сообщением на русском.
4. Обязательная проверка после правки:
   - `node --check` по извлечённому `<script>`;
   - JSON-разбор изменённых констант;
   - проверка связности (см. выше);
   - калькуляторы: 3 контрольных расчёта — взрослый 70 кг, ребёнок 10 кг, граничный возраст;
   - `VERSION` +0.01 и сегодняшняя дата.
   Повторяющиеся проверки оформить скриптом `tools/validate.py` и запускать его.
5. Комментарии в коде — по-русски, коротко: что и почему (`// правка 2026-10: …`).

## Медицинская безопасность
- Иерархия источников: клинические рекомендации МЗ РФ и стандарты медпомощи →
  приказы МЗ РФ → приказы ГАУЗ АССМП и Управления здравоохранения г. Альметьевска →
  МОССМП (опорная версия для алгоритмов — 2026) → инструкция по применению.
  У новой записи указывать источник. Локальные пометки вида «нет в укладке» — в `note`.
- Дозы, концентрации, скорости, пороги (САД, ЧСС, SpO₂), возрастные ограничения —
  не выдумывать и не «округлять по памяти».
- Сомнение или расхождение источников — не вносить молча, а вынести в
  «⚠ Требует проверки»: что именно и где расходится. Решаю я.
- Всегда проверять: единицы (мг/мл/мкг/ЕД; мг/кг; мкг/кг/мин), пересчёт мг → мл по
  концентрации, максимальную разовую и суммарную дозу, детские дозы отдельно.
- Инфузии: на станции нет дозаторов, вводим капельно через систему. В записях —
  «капельно через систему, если нет дозатора». Исключения (формулировку не трогать):
  окситоцин, мидазолам, пропофол, тиопентал, диазепам, атропин, преднизолон.
- Объём линейной бригады: интубация, аппаратная ИВЛ, препараты бригад АиР —
  помечать «вне рамок линейной бригады».
- Противопоказания и критичные предупреждения — заметно (стили `--ban` / `--warn`).
- Если просьба опасна для пациента или противоречит рекомендациям — сказать прямо
  до правки.

## Атлас ЭКГ
- Схемы — только собственные SVG по стандартной сетке (25 мм/с, 10 мм/мВ), без чужих изображений.
- У каждого паттерна: критерии, `leadsSte` / `leadsStd`, артерия-виновник для ИМ,
  `urgency` и `redFlag` (что нельзя делать).

## Интерфейс
- Сначала телефон: от 360 px, без горизонтальной прокрутки, кнопки ≥ 44 px.
- Никаких CDN, внешних шрифтов и сетевых запросов — только офлайн.
- Стили — только через CSS-переменные `:root` (цвета, `--fs-scale`, `--r`, `--sp-*`,
  `--sev0…6`); светлая и тёмная тема обязательны.
- Доза, противопоказание и следующий шаг алгоритма — видны без лишних нажатий.
- Навык `ui-ux-pro-max` (`.claude/skills/`) — справочник UX-правил. Его советы про
  Google Fonts, Tailwind, CDN и фреймворки здесь не применять: правила выше важнее.

## Общение
- По-русски, коротко. Большие куски кода в чат не выводить.
- Итог каждой правки:
  1) что изменено (списком); 2) новая версия; 3) что проверено;
  4) «⚠ Требует проверки» — если есть медицинские сомнения.
- Неоднозначная или дорогая задача (массовая правка, удаление разделов) — сначала
  один уточняющий вопрос.
